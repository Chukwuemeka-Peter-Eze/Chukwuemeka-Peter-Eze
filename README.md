## About

I design, automate, and operate cloud infrastructure across the full delivery lifecycle — from provisioning through deployment, security, and observability. My work sits at the intersection of:

**Cloud Infrastructure → Infrastructure as Code → Containers → Kubernetes → CI/CD → Observability → DevSecOps**

My focus goes beyond individual tools to the systems they compose: how infrastructure is provisioned, how code moves safely into production, how failures are detected and recovered from, and how access and secrets stay secure at scale.

> I don't just learn tools — I design and operate systems built on them.

## Security Mindset

I approach infrastructure with a **security-by-design** philosophy — security is engineered in from the start, not layered on afterward.

```
Identity → Least Privilege → Secure Configuration → Secret Management → Image/Code Scanning → Secure CI/CD → Monitoring → Auditability
```

> Build systems that are difficult to misuse, easy to observe, and repeatable to operate.
