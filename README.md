# 👋 Hi, I'm Chukwuemeka Peter Eze

### Cloud & DevOps Engineer | DevSecOps | Infrastructure Automation

I build **cloud infrastructure, deployment platforms, automation systems, and observable workloads**.

My current engineering focus sits at the intersection of:

**Cloud Infrastructure → Infrastructure as Code → Containers → Kubernetes → CI/CD → Observability → DevSecOps**

I am particularly interested in understanding systems beyond the happy path:

* How infrastructure is provisioned
* How applications move from code to production
* How systems fail
* How failures are detected
* How deployments are automated
* How access is secured
* How infrastructure is observed
* How systems can become more reliable and repeatable

> **I don't want to simply learn tools. I want to understand the systems those tools help us build.**

# 🔐 SECURITY MINDSET

Security is not something I want to bolt onto infrastructure after it has already been built.

I'm developing toward a **security-by-design** approach:

```text
IDENTITY
   ↓
LEAST PRIVILEGE
   ↓
SECURE CONFIGURATION
   ↓
SECRET MANAGEMENT
   ↓
IMAGE / CODE SCANNING
   ↓
SECURE CI/CD
   ↓
MONITORING
   ↓
AUDITABILITY
```

The goal is simple:

> **Build systems that are difficult to misuse, easy to observe, and repeatable to operate.**

# 📈 RELIABILITY & OPERATIONS

I am increasingly interested in the questions that appear **after deployment**:

### What happens when...

* a deployment fails?
* an instance becomes unhealthy?
* a container crashes?
* traffic increases?
* credentials are compromised?
* a pipeline breaks?
* a Kubernetes pod repeatedly restarts?
* monitoring stops reporting?
* infrastructure needs to be recreated?

That is where DevOps becomes more than tooling.

It becomes **engineering**.
